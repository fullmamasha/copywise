# Editorial basis

These notes distinguish published observations from Copywise’s editorial choices. The sample covers public product pages, descriptions of shipped interactions, design systems, and usability research. The examples in the skill are original teaching examples.

## Product decisions worth studying

| Public product surface | What the source shows | How Copywise uses it |
| --- | --- | --- |
| Wise transfer tracker | The journey distinguishes receiving funds and sending them to the recipient’s bank. | Ask which event is confirmed before naming a state. A sent transfer cannot establish receipt. [Wise tracker guide](https://wise.com/help/articles/2452305/how-do-i-check-my-transfers-status) |
| Duolingo streak milestone | The team studied learners who found the flame metaphor unfamiliar and redesigned milestone celebrations. | Give celebration a recognizable achievement. A person should understand the result even if the metaphor is unfamiliar. [Duolingo design retrospective](https://blog.duolingo.com/streak-milestone-design-animation/) |
| Linear project templates | A template can include a project’s milestones, issues, and owner. The creation flow applies it to a new project. | Retain distinctions between a template, one project created from it, and the work inside that project. Changing a noun can change perceived scope. [Linear project templates](https://linear.app/changelog/2023-09-21-project-templates) |
| Stripe Payment Links | The product page explains how to create a link and shows the link being used to collect payment. | Demonstrate a benefit through the thing the buyer can make and how someone uses it. [Stripe Payment Links](https://stripe.com/checkout/payment-links) |

## Articles and guidance

| Question | Finding and practical application |
| --- | --- |
| How do people scan? | Eye-tracking research describes readers using informative subheadings to select where to read. Review headings alone, then check whether the body fulfills each heading’s promise. [Nielsen Norman Group](https://www.nngroup.com/articles/layer-cake-pattern-scanning/) |
| How much personality belongs in an error? | Mailchimp ties humor to context and discourages forcing it. GOV.UK considers the stress of a public-service transaction. Copywise uses category defaults and a separate adjustment for the state. [Mailchimp](https://styleguide.mailchimp.com/voice-and-tone/) · [GOV.UK](https://www.gov.uk/service-manual/design/writing-for-user-interfaces) |
| What should a CTA promise? | GOV.UK describes actions in button labels. Baymard’s checkout examples show how wording distinguishes order review from commitment. Copywise has the writer trace the control to its next event. [GOV.UK buttons](https://design-system.service.gov.uk/components/button/) · [Baymard](https://baymard.com/blog/button-design) |
| How should empty states and errors differ? | Carbon distinguishes reasons a surface has no data. GOV.UK separates input errors from issues the person cannot fix. Write the reason and action available in this state. [IBM Carbon](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states) · [GOV.UK errors](https://design-system.service.gov.uk/components/error-message/) |
| Will the message reach its reader? | W3C WAI covers both field-level and overall form feedback. Its guidance on reflow and text spacing informs the layout checks. [Feedback](https://www.w3.org/WAI/tutorials/forms/notifications/) · [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) · [Text spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html) |

The four voice profiles, choice of categories, and sample rewrites are design decisions for this skill. They have not been validated as a conversion model or a substitute for research with a product’s own users.
