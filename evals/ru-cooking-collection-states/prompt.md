Используй Copywise. Кулинарное приложение, к пользователю обращаемся на «ты», тон дружелюбный. Нужны тексты для раздела сохранённых рецептов в трёх состояниях: 1) коллекция пустая, кнопка ведёт в каталог рецептов; 2) человек только что сохранил свой первый рецепт «Паста с печёным перцем» (тост после нажатия на сердечко); 3) поиск ужинов с фильтрами ничего не нашёл, есть кнопка сброса фильтров. Пол пользователя мы не знаем. Дай готовые строки по компонентам.
